# RESTAURANT-CHECKOUT-SUMMARY-LAYOUT

تغییر component انجام شد: دکمهٔ تأیید فعال قرمز با متن سفید، راهنما فقط تا قبل از تأیید، و اقلام و مبالغ در یک جدول پیش از دکمه‌های پرداخت قرار دارند. محاسبات و adapter تغییر نکردند.

آزمون‌های `restaurant-checkout.test.cjs` و `restaurant-otp-test-polish.test.cjs`: هر ۲۸ مورد موفق. سرویس موجود روی 3333 پاسخ HTTP 200 داد؛ هیچ سرویس دیگری راه‌اندازی یا متوقف نشد.

مرورگر Playwright MCP روی runtime موجود در چهار حالت 596×1013 و 390×844 با دو تم: دکمه غیرفعال و رنگ فعال، پایداری ابعاد حین ورود رقم‌به‌رقم، راهنمای پیش و پس از OTP و بازگشت پس از تغییر شماره، چهار ستون و چهار ردیف جمع، ترتیب پرداخت، کنترل تعداد و نبود overflow بررسی شد. WELCOME مبلغ تخفیف ۱۰٬۰۰۰ و قابل پرداخت ۸۰٬۰۰۰ تومان را از bill نمایش داد؛ بازگشت از OTP شماره و focus را حفظ کرد. تصاویر: `.playwright-mcp/summary-{light,dark}-{596,390}.png`. selector آزمون پیشین به `tfoot` تغییر یافت؛ خود آن مجموعه کامل دوباره اجرا نشد. هیچ سفارش یا پرداختی انجام نشد و runtime دست‌نخورده ماند.
